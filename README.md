## הכלים
| קובץ | מה עושה |
|---|---|
| `ingest.py` | סורק את המקורות (`lib/adapters.py`, קריאה בלבד) → `data/items.json`. תיבות חיתוך ללוחות: `cache/boxes.json` |
| `make_lexicon.py` | מילון המושגים עברית ← נרדפות + אנגלית → `data/lexicon.json`. מוסיפים מושגים בקוד ומריצים |
| `find_images.py` | חיפוש + גיליון ממוספר `sheets/…jpg` + `sheets/last.json` |
| `pick.py` | מעתיק לספר (בלי כיתובים / חתוך), רושם ב-`picks.json` וב-`data/usage.json` |
| `TAG.md` + `check_tags.py` | תיוג עברי (`he_title`, `he_tags`) ע"י סוכנים → `data/tagparts/` → `--merge` → `data/tags.json` |
| `build_site.py` | הגלריה `docs/` (תמונות קטנות `t/`, לוחות חתוכים `f/`, `lib.json`; תמונות מלאות מהכתובות הקיימות) |
| `update.py` | הכול ברצף + push. פריטים חדשים בלי תגיות → `data/tagjobs/new.json` |

**קבצים יקרים – לא לבנות מחדש:** `data/tags.json` (תיוג), `data/review.json` (החלטות בדיקה), `data/usage.json`.
`items.json` נבנה מחדש בכל `ingest`.

## חיפוש
נרמול עברית (`lib/hebrew.py`, ואותו קוד ב-`docs/index.html`): בלי ניקוד, אותיות סופיות, גרסאות בלי תחיליות
(ו/ה/ב/ל/מ/ש/כ) ובלי סיומות רבים. המילון מרחיב לנרדפות ולמילים באנגלית שבתיאורים.
משקלים: תגיות 3, כותרת 2.5, כיתוב 2, נושא 1.5, אנגלית 1.5, הקשר (שאלה, סעיף) 0.7. גיוון: עד 3 מאותו חידון.

## הוספת תמונות
- חידון/פרק חדש בספר החגים – `python update.py` מוצא לבד, ואז מתייגים את `data/tagjobs/new.json`.
- **לוחות:** אפשרות 0 = הלוח **הימני** (`crop = boxes[2 - k]`), כמו במנוע החידונים.
- מקור חדש – מתאם חדש ב-`lib/adapters.py`. מקור שלא נבדק בעין – `reviewed: False`, ונכנס לגלריה ולחיפוש
  רק אחרי `data/review.json` → `{"<id>": {"status": "ok"}}`.
